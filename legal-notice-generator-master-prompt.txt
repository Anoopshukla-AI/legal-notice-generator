APP_NAME:               Legal Notice Generator
ONE_LINE_DESCRIPTION:   Generates a formatted legal notice or contract clause
                        from a web form — rent demand, cheque dishonour,
                        NDA, eviction, money recovery, employment termination —
                        as a copyable and downloadable .txt file.
PRIMARY_USER:           Indian individuals and small business owners who need a
                        legal notice draft and do not have a lawyer on retainer.
CORE_PROBLEM:           Writing a legally structured notice from scratch is
                        intimidating and time-consuming. Existing tools either
                        force a consultation booking or only serve the US market.
                        Users need a correct-format starting point they can
                        copy and send today.
PRIMARY_KEYWORD:        legal notice generator
SECONDARY_KEYWORDS:     rent agreement format India, contract clause generator,
                        demand letter generator, NDA template generator,
                        cheque bounce notice format
COUNTRY_TARGETING:      India (primary), Global (secondary for NDA + demand
                        letter types)
MONETIZATION_MODEL:     AdSense — legal CPC is $4–$14 per click; lawyer
                        directories (Justdial, Avvo, LegalZoom) bid $6–$18.
                        Place AdSense slots: (1) between hero and disclaimer,
                        (2) between tool and educational section, (3) between
                        FAQ and footer. Do not place ads inside the tool panel.

CORE FEATURES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

FEATURE_1: Notice Type Selector
  Dropdown with 6 notice types. Selecting a type reveals only the fields
  relevant to that notice. No unused fields are ever visible.
  Types: Rent Demand Notice | Money Recovery Demand Letter |
         NDA Confidentiality Clause | Eviction Notice |
         Employment Termination Notice | Cheque Dishonour Notice (S.138 NI Act)

FEATURE_2: Dynamic Form with Contextual Fields
  4 universal fields (sender name, recipient name, date, notice type) +
  3–5 type-specific fields that appear via JS on type selection.
  Every field has a helper hint explaining WHY the field matters legally,
  not just what it is. Validation fires on Generate click with inline
  field-level error messages.

FEATURE_3: Real-Time Preview Panel
  Side-by-side on desktop (form left, preview right). Monospace font.
  Preview updates live (debounced 600ms) as the user edits fields once a
  notice has been generated once. Empty state shows a document icon and
  "Fill the form and click Generate Notice." No content flicker.

FEATURE_4: Copy & Download
  Copy button: writes full notice text to clipboard via navigator.clipboard
  with a textarea fallback. Shows a "Copied" toast for 2.5 seconds.
  Download button: generates a .txt file named
  "legal-{notice-type}-{YYYY-MM-DD}.txt" via JS Blob + createObjectURL.
  Both buttons are disabled until a notice has been generated.

FEATURE_5: Educational + FAQ Section (SEO/GEO)
  Below the tool: 6 topic cards explaining each notice type and how to send
  notices in India (RPAD, email, when to use a lawyer). FAQ accordion with
  5 questions matching the FAQPage JSON-LD schema exactly.
  Answer-first paragraph style for GEO extractability.

FORMULA / LOGIC
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

FORMULA_1: Notice text assembly
  Plain language:
    For each notice type, concatenate fixed legal-language blocks with
    interpolated user values. No calculation involved — string interpolation
    of validated user inputs into a fixed template string per notice type.
  Pseudocode:
    function generateNotice(type, data):
      template = TEMPLATES[type]          // fixed string with {placeholders}
      return template.replace(placeholders, sanitize(data[key]))
    function sanitize(value):
      if empty → return "[NOT PROVIDED]"  // never leave a blank placeholder
      return value.trim()

FORMULA_2: Currency formatting
  Plain language:
    Format numeric amounts as Indian locale currency.
    e.g. 120000 → ₹1,20,000/-
  Pseudocode:
    function formatINR(n):
      return "₹" + n.toLocaleString("en-IN") + "/-"

FORMULA_3: Date formatting
  Plain language:
    Render ISO date strings as Indian long-form dates.
    e.g. 2025-06-03 → 3rd June 2025
  Pseudocode:
    function formatDate(iso):
      return new Date(iso).toLocaleDateString("en-IN",
        { day: "numeric", month: "long", year: "numeric" })

EDGE_CASES:
  - Reply deadline < 1: block with validation error "Minimum 1 day required."
  - S.138 cheque bounce: reply deadline is always 15 days (locked). Do not
    allow the user to change it. If field is tampered via DevTools, clamp
    silently to 15 before generation.
  - Amount = 0 or negative: block with "Amount must be greater than zero."
  - Empty optional field (e.g. notice pay): omit the corresponding sentence
    from the output entirely. Do not print "[NOT PROVIDED]" in optional fields.
  - NDA duration > 10 years: block with "Standard NDA periods are 1–10 years."
  - Date of notice in the past by > 30 days: show a warning (not a block):
    "This date is more than 30 days in the past. Verify this is intentional."
  - All text fields: trim whitespace. Do not allow only-whitespace inputs to
    pass validation.
